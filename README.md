# 🌙 Eclipse Ox Pack

A complete visual redesign of the Overextended essentials, in one cohesive, modern package.
**Eclipse Ox Pack** restyles **ox_inventory**, **ox_target**, and **ox_lib** so every part of your server's interface looks like it belongs together. Same rock-solid functionality, completely new look.
Built for server owners who love the ox ecosystem but want a UI that feels premium, consistent, and unique to their server.

## 🚀 Why Eclipse Ox Pack?

The default ox interfaces are functional, but they look the same on every server. Mixing them with custom-designed scripts creates a mismatched, unpolished experience.
**Eclipse Ox Pack** redesigns the three UIs your players see most, so your inventory, interaction eye, and every notification, menu, and progress bar share one modern design language, matching all Eclipse `ec_*` resources.

---

## ✨ Features

* **🎒 Redesigned Inventory (ox_inventory):** A clean, modern layout with refined slots, item tooltips, hotbar, and context menus. Fully compatible with the original ox_inventory logic.
* **👁️ Redesigned Target (ox_target):** A minimal eye indicator and a sleek option list with smooth hover and select animations.
* **📚 Redesigned Library UI (ox_lib):** Restyled notifications, context menus, input dialogs, alert dialogs, progress bars and circles, radial menu, text UI, and skill checks.
* **🎨 One Consistent Design Language:** Shared colors, typography, and spacing across all three resources.
* **🧩 Drop-In Replacement:** Only the interface is replaced. Your exports, events, configs, and existing scripts keep working.
* **⚡ Lightweight & Optimized:** Smooth animations without hurting client performance.
* **🖌️ Easy Customization:** Change accent colors and styling from a single place.
* **📱 Responsive Layout:** Scales cleanly across common resolutions.
